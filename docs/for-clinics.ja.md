# 医療機関・中小企業の方へ（CVE-2026-111497 点検ツール）

## このツールは、どなたが使うものか

**保守を担当する事業者や IT 担当者が実行するものです。** 院長先生や事務の方がご自分で実行する
ものではありません。結果を受け取った方は、このページの「結果の受け取り方」だけ読んでいただければ十分です。

## 何を調べるツールか

インターネットで広く使われている圧縮の仕組み「Brotli（ブロトリ）」に、外部から送られたデータで
サーバーを乗っ取られうる欠陥（CVE-2026-111497）が見つかりました。このツールは、1 台のサーバーの中に
その欠陥を持つ部品が残っていないかを、**中身を一切変更せずに**洗い出します。

## 結果の受け取り方

結果の最後に、次の 4 行の要約が出ます。見るのはここだけで結構です。

```
更新が必要なもの: 3 件
再起動が必要なもの: 1 件
人の確認が必要なもの: 2 件
走査しなかった範囲: ...
```

- **「更新が必要なもの」が 0 件でない** → 事業者に対応を依頼してください（下記）。
- **「再起動が必要なもの」が 0 件でない** → 対象のサービスの再起動が必要です。業務への影響が
  少ない時間帯を事業者と相談してください。
- **「人の確認が必要なもの」** → 事業者が製品の提供元に確認します。すぐに危険という意味ではありません。
- **「走査しなかった範囲」** → 調べていない場所です。すべて 0 件でも「安全」という意味ではありません。

## 「更新が必要なもの」が 0 件でないとき、事業者に頼むこと

1. 結果に挙がった部品を、修正版に更新してください（結果の各行に更新先が書いてあります）。
2. 更新後に関係するサービスを再起動し、もう一度このツールで確認してください。
3. 更新までの間に外部からの攻撃を受けていないか、別途調査してください（このツールは侵入の有無を調べません）。

## 大切な注意

**このツールは侵入の有無を調べません。修正版に更新しても、更新前の侵入の痕跡は消えません。**
外部に公開しているサーバーで「更新が必要なもの」が見つかった場合は、更新とあわせて侵入の痕跡の
調査も事業者にご相談ください。
