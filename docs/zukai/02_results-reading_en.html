How to read this page

  1. Rows are where the copy lives; columns are the OS. In the top row (shipped by the OS), all five images built on 2026-10-27 report FIXED: Ubuntu fixed 22.04, 24.04, 26.04 and 26.10 on 2026-10-26 (USN-8956-1), and Debian 12 and 13 were already fixed. A host not updated since then has them VULNERABLE: update with apt and restart what uses them. The bottom row (bundled in products) is the same on every OS. Unfixed copies were placed on purpose, so every run ends with exit status 1 (the correct result).
  2. Read the four-line Summary at the end. “Needs update” = VULNERABLE + LIKELY_VULNERABLE; “Needs restart” = RESTART_REQUIRED; “Needs human review” = NO_FIX_AVAILABLE + VENDORED_COPY + UNKNOWN + LIKELY_FIXED; then “Not scanned”. Example: the Ubuntu 24.04 sample output (docs/sample-output.md) shows “Needs update: 2, Needs restart: 0, Needs human review: 0”: the Node.js 22.23.3 and PyPI Brotli 1.2.0 placed on purpose.
  3. Exit status 0 does not mean “safe”. It only means nothing needing action was found in the scanned ranges. The tool does not judge whether attacker data can reach a decoder it found (EXPOSURE is a hint), and does not check for intrusion. The advisory data is a snapshot as of 2026-10-27 (with the data of 2026-10-26, Ubuntu's packages were reported as NO_FIX_AVAILABLE; docs/design.md 2.1).
